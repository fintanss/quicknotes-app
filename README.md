
# QuickNotes

QuickNotes is a simple browser-based note-taking application built with HTML, CSS, and JavaScript. It allows users to create notes, organize them into Personal, Work, and Study categories, search notes, and delete notes. Notes are saved in the browser using localStorage, so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work, or Study categories.
- Validate notes to prevent empty entries and notes longer than 200 characters.
- Display each note with its category and creation date.
- Delete individual notes.
- Search notes without case sensitivity.
- Display the total number of saved notes.
- Save notes using localStorage so they survive page refreshes.
- Responsive layout for mobile and desktop screens.

## How to Run Locally

1. Clone or download this repository.
2. Open the `quicknotes-app` folder in Visual Studio Code.
3. Open `index.html` in a web browser, or use the Live Server extension.
4. Add, search, and delete notes.

No server or package installation is required.
